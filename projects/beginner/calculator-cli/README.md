# Calculator CLI

## Goal

Build a console calculator that performs addition, subtraction, multiplication, and division.

## Requirements

- Show a menu of operations.
- Read two numbers from the user.
- Print the result.
- Reject division by zero.
- Let the user perform more than one calculation.

## Starter Structure

```text
CalculatorApp.java
Calculator.java
```

## Milestones

1. Implement one operation.
2. Add all four operations.
3. Add input validation.
4. Add unit tests.
