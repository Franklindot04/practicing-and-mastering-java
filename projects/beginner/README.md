# Beginner Projects

Beginner projects focus on variables, conditionals, loops, methods, arrays, strings, classes, and basic console input/output.

## Recommended Order

- [Calculator CLI](calculator-cli/README.md)
- [Number Guessing Game](number-guessing-game/README.md)
- [To-Do List CLI](todo-list-cli/README.md)
- [Student Grade Calculator](student-grade-calculator/README.md)
- [Simple Banking Simulation](simple-banking-simulation/README.md)
- [Contact Book](contact-book/README.md)

Build one project at a time. Keep the first version small, then add validation, tests, and persistence later.

## Before You Start

- [ ] Read [Getting Started](../../docs/00-getting-started/README.md).
- [ ] Complete the core [Java Basics](../../docs/01-java-basics/README.md) notes.
- [ ] Practice with [Beginner Exercises](../../exercises/beginner/README.md).

## After Each Project

- [ ] Run the project from the terminal.
- [ ] Change one feature and test it manually.
- [ ] Take a related [Beginner Quiz](../../quizzes/beginner/README.md).
- [ ] Review [Beginner Solutions](../../solutions/beginner/README.md) only after attempting the project yourself.
