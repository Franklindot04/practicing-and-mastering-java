# Scalable Commerce Backend Reference Architecture

This project is a Java-based architecture reference and deterministic simulator for advanced backend system design decisions. It models commerce boundaries without claiming to be a deployed production platform.

## Business Areas

- product catalogue
- search
- pricing
- inventory
- cart
- checkout
- payment
- order lifecycle
- shipment
- notification
- customer account boundary
- administration boundary

## Run

```bash
mvn test
```
