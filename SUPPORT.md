# Support

This repository is maintained as a learning resource.

For help:

- Open a topic request if a concept needs clearer explanation.
- Open an exercise request if you want more practice for a topic.
- Open a project idea if you want to suggest portfolio work.
- Open a bug report if an example, command, or explanation is incorrect.

Please include the Java version, operating system, command run, and exact error message when asking for technical help.
