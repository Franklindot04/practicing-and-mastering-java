# Architecture Scenarios

1. AS-01: Design the boundary between catalogue, inventory, and checkout for a commerce service.
2. AS-02: Choose between synchronous HTTP and asynchronous events for shipment notification and explain the trade-off.
3. AS-03: Design a workflow task lease model that supports safe reassignment.
4. AS-04: Explain how a cache-aside product read can become stale and how to handle it.
5. AS-05: Propose data ownership boundaries for a scalable order platform.
6. AS-06: Explain how to evolve an event schema compatibly.
7. AS-07: Identify which parts of a capstone architecture would need real infrastructure before deployment.
8. AS-08: Design a review checklist for a final repository release candidate.
