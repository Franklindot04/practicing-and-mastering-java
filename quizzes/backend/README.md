You should be able to explain HTTP methods, status codes, DTOs, services, controllers, validation, error responses, common Spring Boot annotations, basic service testing, SQL basics, repositories, entities, transaction boundaries, authentication, authorization, password hashing, token tradeoffs, and basic Spring Security route protection.
