# System Design Interview Quiz

1. What should you do before drawing components?
2. How do you communicate assumptions without pretending they are facts?
3. How would you handle an interviewer asking for "infinite scale"?
4. Why should you discuss tradeoffs out loud?
5. How can you show that you understand operations?
6. How can you avoid architecture absolutism?
7. What should you do when there are multiple valid designs?
8. What is a good closing summary for a system design interview?
