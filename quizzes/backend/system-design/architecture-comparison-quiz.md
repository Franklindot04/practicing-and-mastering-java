# Architecture Comparison Quiz

For each prompt, choose a reasonable design direction and explain tradeoffs.

1. One team owns a new product with unclear domain boundaries. Compare modular monolith and microservices.
2. A reporting feature has expensive reads but can be 10 minutes stale. Compare direct queries, caching, and a read model.
3. A mobile client and web client need different response shapes. Compare a shared API, API gateway, and backend-for-frontend.
4. A legacy inventory system has confusing field names. Compare direct integration and an anti-corruption layer.
5. A checkout workflow touches inventory, payment, and notification. Compare orchestration and choreography.
