# Capacity Estimation Quiz

1. A service receives 2,000,000 reads per day. Estimate average reads per second.
2. A service receives 100,000 writes per day. Estimate average writes per second.
3. Why is a daily average insufficient for capacity planning?
4. If peak traffic is 8x average, what should you monitor after launch?
5. A tenant produces 60 percent of all writes. What design risk does this create?
6. Why can horizontal API scaling fail to improve throughput?
7. Name two cost signals that can grow with traffic.
