# Multiple Choice Quiz

1. Which item is a functional requirement?
   - A. The service responds within 300 ms
   - B. Users can create an order
   - C. The system has 99.9 percent availability
   - D. Logs exclude sensitive data

2. Scalability means:
   - A. Current requests are fast
   - B. The system can handle growth by adding or changing resources
   - C. Data survives disk failure
   - D. Every service is stateless

3. Availability differs from reliability because availability asks whether:
   - A. Data is permanently stored
   - B. The system can respond when needed
   - C. The answer is always correct
   - D. The database is normalized

4. A retry is safest when:
   - A. The caller is impatient
   - B. The operation is idempotent or otherwise safe
   - C. The system has no logs
   - D. The request is a payment with no idempotency key

5. A modular monolith can be a good starting point when:
   - A. One team owns an evolving domain
   - B. Every domain requires independent deployment today
   - C. Network failure should be added intentionally
   - D. Shared mutable internals are acceptable

6. Replication is different from partitioning because replication:
   - A. Divides data into shards
   - B. Keeps copies of data
   - C. Removes consistency concerns
   - D. Eliminates backups

7. Caching can be risky because:
   - A. It always lowers correctness
   - B. It can introduce stale data and invalidation complexity
   - C. It cannot improve latency
   - D. It removes database load permanently

8. A design assumption is:
   - A. A verified production measurement
   - B. A guess used to move design forward
   - C. A production credential
   - D. A deployment manifest
