# Distributed Systems Multiple Choice Quiz

## Questions

1. What is a partial failure?
   - A. The whole system shuts down at once.
   - B. One part of the system fails while other parts continue running.
   - C. A compiler catches only some errors.
   - D. A request is always retried successfully.

2. During a network partition, CAP theorem is mainly about choosing between:
   - A. Logs and metrics.
   - B. Consistency and availability for a specific behavior.
   - C. Java and another programming language.
   - D. REST and GraphQL.

3. Which operation is naturally closest to idempotent?
   - A. Increment task priority.
   - B. Append a comment.
   - C. Set task completed to true.
   - D. Create a new task without a key.

4. What can make retries safer?
   - A. Infinite attempts.
   - B. No timeout.
   - C. Idempotency, limits, backoff, and jitter.
   - D. Retrying all validation errors.

5. What is a saga?
   - A. A single database transaction inside one table.
   - B. A long-running workflow made of local transactions and compensation actions.
   - C. A service discovery registry.
   - D. A cache invalidation rule.

6. What does service discovery help with?
   - A. Finding healthy service instances.
   - B. Encrypting passwords.
   - C. Compiling Java code.
   - D. Avoiding all network failures.

7. Why can distributed locks be dangerous?
   - A. They are always local memory locks.
   - B. Ownership depends on network communication, leases, and failure detection.
   - C. They remove the need for idempotency.
   - D. They make stale writes impossible by default.

8. What does distributed tracing show?
   - A. Only source code style problems.
   - B. The path and timing of work across components.
   - C. The exact business answer to every conflict.
   - D. A replacement for all logs and metrics.
