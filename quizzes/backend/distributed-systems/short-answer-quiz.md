# Distributed Systems Short Answer Quiz

Answer in a few sentences each.

1. Explain the difference between a monolith and a distributed system without saying one is always better.

2. Why can a response timeout leave the caller uncertain about whether the work happened?

3. Give one example of data that needs strong or read-after-write consistency and one example that can be eventually consistent.

4. What should happen if the same idempotency key is reused with a different request payload?

5. Why should retries usually have a maximum attempt count?

6. What is a compensation action in a saga?

7. Why is leader election harder than "pick the first running instance"?

8. Name four signals that help investigate a distributed failure.
