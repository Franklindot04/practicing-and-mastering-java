# Benchmark Smell Identification Quiz

Identify the smell.

1. The benchmark has no warm-up.
2. The loop computes a value that is never used.
3. Only one run is reported.
4. Inputs are one compile-time constant string.
5. The result claims production capacity from a microbenchmark.
6. A unit test fails if an operation takes more than 5 ms on any laptop.
7. Average latency is reported without percentiles or errors.
