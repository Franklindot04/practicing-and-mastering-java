# Thread State Interpretation Quiz

1. Many threads are `BLOCKED` on the same monitor. What does this suggest?
2. Worker threads are `WAITING` in an idle executor. Is that automatically bad?
3. Many threads are `TIMED_WAITING` during database calls. What else should you inspect?
4. A thread is `RUNNABLE` but not using Java CPU. What native or OS behavior might explain it?
5. Why should you capture more than one thread dump?
