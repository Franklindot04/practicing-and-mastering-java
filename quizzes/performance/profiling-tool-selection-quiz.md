# Profiling Tool Selection Quiz

Choose the most useful evidence source.

1. CPU is high and you need hot Java methods.
2. Requests are slow but CPU is low and threads wait on locks.
3. Heap keeps growing after each workload cycle.
4. You need a low-overhead event recording from a local JVM.
5. You need a quick snapshot of thread states.
6. You need class instance counts by live bytes.
7. You need to correlate logs, metrics, traces, and profiles during an incident.
