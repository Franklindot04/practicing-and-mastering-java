# Percentile Interpretation Quiz

Given:

| Metric | Value |
| --- | ---: |
| average | 80 ms |
| p50 | 40 ms |
| p95 | 300 ms |
| p99 | 1,400 ms |
| max | 5,000 ms |

1. What does p95 mean?
2. Why might users still complain when the average is 80 ms?
3. Which metric suggests rare severe delays?
4. What other signal should be analyzed with latency?
5. Name two possible causes of the tail.
