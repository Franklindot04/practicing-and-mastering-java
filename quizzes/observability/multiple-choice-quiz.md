# Observability Multiple Choice Quiz

1. Which statement best distinguishes monitoring from observability?
   - A. Monitoring collects logs; observability collects metrics.
   - B. Monitoring checks known conditions; observability helps investigate system behavior from evidence.
   - C. Monitoring is only for development; observability is only for production.
   - D. They are unrelated practices.

2. Which field is usually unsafe as a metric label?
   - A. `operation=createOrder`
   - B. `outcome=success`
   - C. `requestId=req-123`
   - D. `dependency=payment`

3. What is the strongest reason to prefer latency histograms over averages?
   - A. Histograms never require storage.
   - B. Averages reveal tail latency exactly.
   - C. Histograms support distribution and percentile reasoning.
   - D. Averages are not numbers.

4. What does readiness answer?
   - A. Should this instance receive traffic or work?
   - B. Should the process be restarted?
   - C. Has the source code compiled?
   - D. Does the service have perfect observability?

5. What is an SLO?
   - A. A contractual penalty.
   - B. A target for a service-level indicator.
   - C. A raw log event.
   - D. A trace span identifier.
