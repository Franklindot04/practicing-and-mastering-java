# Templates

Use templates to keep learning content consistent.

## Available Templates

- `concept-note-template.md`
- `exercise-template.md`
- `project-template.md`
- `quiz-template.md`

## How To Use

1. Copy the template structure into the correct topic folder.
2. Replace placeholder text with specific content.
3. Add examples and common mistakes.
4. Add practice prompts.
5. Keep explanations beginner-friendly.

## Quality Bar

Every note should answer:

- What is this?
- Why does it matter?
- How do I use it?
- What mistakes should I avoid?
- How can I practice it?
