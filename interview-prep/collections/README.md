# Collections Interview Prep

Know when to use each structure:

| Need | Collection |
| --- | --- |
| Ordered values with duplicates | `ArrayList` |
| Unique values | `HashSet` |
| Unique values in insertion order | `LinkedHashSet` |
| Sorted unique values | `TreeSet` |
| Key-value lookup | `HashMap` |
| Sorted keys | `TreeMap` |
| FIFO processing | `ArrayDeque` |
| Priority processing | `PriorityQueue` |

Practice explaining time complexity in plain language.
