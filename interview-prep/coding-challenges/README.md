# Coding Challenges

Use these prompts to practice clear problem solving.

## Beginner

- Reverse a string.
- Count vowels.
- Find the largest number in an array.
- Check if a number is prime.
- Implement fizz buzz.

## Intermediate

- Count word frequency.
- Find duplicates.
- Sort objects by multiple fields.
- Validate parentheses.
- Merge two sorted lists.

## Advanced

- Implement an LRU cache.
- Process files concurrently.
- Build a small task scheduler.
- Parse and summarize log lines.

## Challenge Template

For each challenge, write:

- Problem statement
- Input and output
- Edge cases
- Approach
- Complexity
- Tests
