# Collections Examples

Compile and run:

```bash
javac examples/intermediate/collections/CollectionsDemo.java
java -cp examples/intermediate/collections CollectionsDemo
```

This demo covers `List`, `ArrayList`, `LinkedList`, `Set`, `HashSet`, `LinkedHashSet`, `TreeSet`, `Queue`, `Deque`, `PriorityQueue`, `Map`, `HashMap`, `LinkedHashMap`, `TreeMap`, iterators, `Comparable`, `Comparator`, and the `Collections` utility class.
