# Intermediate Java Examples

Compile and run examples individually:

```bash
javac examples/intermediate/java/GenericsDemo.java
java -cp examples/intermediate/java GenericsDemo
```

Examples included:

- `GenericsDemo.java`
- `ExceptionsFilesDemo.java`
- `LambdasStreamsOptionalDemo.java`
- `DateTimeDemo.java`

The file example creates and deletes `java-practice-note.txt` in the current working directory.
