# Cloud Architecture Foundations

Cloud architecture is the practice of designing how applications, infrastructure, data, network paths, operations, and cost controls fit together in a cloud environment.

This section is vendor-neutral and educational. It does not create cloud resources, prescribe a provider, or provide production-ready designs.

## Learning Goals

- Explain cloud architecture at a beginner-to-intermediate level.
- Separate application architecture from infrastructure architecture.
- Identify tradeoffs in availability, reliability, scalability, and cost.
- Recognize single points of failure.
- Understand why demo diagrams are not production architecture.
