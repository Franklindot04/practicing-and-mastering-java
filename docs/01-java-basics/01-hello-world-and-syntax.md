# Hello World And Java Syntax

## Core Idea

Java programs are usually written inside classes. The `main` method is the starting point for a simple console program.

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

## Why It Matters

Understanding the shape of a Java program helps you read examples without being distracted by every keyword at once.

## Common Mistakes

- Forgetting semicolons.
- Mismatching braces.
- Using a file name that does not match the public class name.
- Writing `Main` when the file is named `HelloWorld.java`.

## Practice Prompts

- Print your name.
- Print three separate lines.
- Change the message and run the program again.

## Before Moving On

You should understand where the class begins, where `main` begins, and which line prints text.
