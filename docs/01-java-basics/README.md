# Java Basics

## Why This Matters

Java basics are the foundation for every later topic. If variables, conditions, loops, methods, arrays, and strings feel shaky, object-oriented programming and collections will feel much harder than they need to.

## Topics In This Section

- [Variables, data types, and operators](02-variables-data-types-operators.md)
- [Input, output, conditionals, and loops](03-input-output-conditionals-loops.md)
- [Methods, arrays, and strings](04-methods-arrays-strings.md)
- [Debugging and problem solving](05-debugging-problem-solving.md)

## Learning Goal

By the end of this section, you should be able to write small console programs that read input, make decisions, repeat work, organize code into methods, and store multiple values.

## Practice Flow

After reading each note:

1. Run a matching file from [beginner examples](../../examples/beginner/README.md).
2. Complete a prompt from [beginner exercises](../../exercises/beginner/README.md).
3. Build or improve one [beginner project](../../projects/beginner/README.md).
4. Use [beginner quizzes](../../quizzes/beginner/README.md) to check understanding.

Before starting OOP, complete at least one project and explain your code without reading from the notes.
