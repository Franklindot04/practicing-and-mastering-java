# Variables, Data Types, And Operators

## Core Idea

A variable stores a value. A data type tells Java what kind of value the variable can hold.

```java
int age = 25;
double price = 19.99;
boolean isLearning = true;
char grade = 'A';
String name = "Franklin";
```

## Common Types

- `int` for whole numbers.
- `long` for larger whole numbers.
- `double` for decimal numbers.
- `boolean` for true or false.
- `char` for one character.
- `String` for text.

## Operators

```java
int total = 10 + 5;
int remainder = 10 % 3;
boolean canVote = age >= 18;
```

## Why It Matters

Most bugs in beginner programs come from storing the wrong kind of value, mixing up operators, or misunderstanding integer division.

## Common Mistakes

- Expecting `5 / 2` to produce `2.5`; with integers it produces `2`.
- Using `=` when you meant `==`.
- Choosing `double` for money in serious applications.
- Forgetting that `String` starts with an uppercase `S`.

## Practice Prompts

- Store a name, age, and favorite programming language.
- Calculate the area of a rectangle.
- Convert minutes into hours and remaining minutes.

## Before Moving On

You should understand declaration, assignment, primitive types, `String`, arithmetic operators, and comparison operators.
