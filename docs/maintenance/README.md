# Repository Maintenance

This repository grows through focused branches. Maintenance work keeps the learning path coherent as new notes, examples, exercises, projects, and quizzes are added.

## Maintenance Checklist

- Keep topic folders numbered and in learning order.
- Link notes to matching examples and exercises when available.
- Check that runnable examples compile.
- Remove generated `.class` files and `target/` directories before committing.
- Keep beginner-facing explanations clear and practical.
- Mark intentionally unsafe demo code clearly.
- Review dependencies before adding them.

## Branch Review Checklist

- Does the branch have one clear purpose?
- Are files in the correct folder?
- Are examples small enough for learners?
- Are exercises specific and testable?
- Are solutions separated from exercises?
- Are there any secrets, credentials, or generated artifacts?
