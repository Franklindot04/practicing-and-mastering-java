# Linking Guide

As the repository grows, each major topic should connect four learning surfaces:

1. Concept notes in `docs/`
2. Runnable examples in `examples/`
3. Exercises in `exercises/`
4. Solutions in `solutions/`

## Suggested Topic Footer

Add this style of footer to mature topic notes:

```markdown
## Related Practice

- Examples: `examples/intermediate/topic-name`
- Exercises: `exercises/intermediate/topic-name.md`
- Solutions: `solutions/intermediate/topic-name.md`
- Quiz: `quizzes/intermediate/topic-name.md`
```

## Link Rules

- Prefer relative repository paths.
- Keep links stable when possible.
- Update links when files move.
- Do not link to missing files unless the note clearly says "coming later."
