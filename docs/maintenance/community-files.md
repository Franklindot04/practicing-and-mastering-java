# Community File Maintenance

The foundation branch adds core community files such as `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, issue templates, and the pull request template.

Review these files when:

- Contribution workflow changes.
- Security reporting guidance changes.
- New issue types are needed.
- Project scope changes.
- The repository starts accepting broader community contributions.

Do not add third-party notices unless third-party material is actually included.
