# CI/CD Foundations

CI/CD helps teams check changes automatically before and after they are merged.

- CI means continuous integration: build and test changes frequently.
- CD can mean continuous delivery or continuous deployment. In this repository, treat CD as a later topic. Start with CI and safe build checks.

## Why It Matters

Automated checks catch mistakes before they reach other learners or users. They also make pull requests easier to review because the basic test workflow is repeatable.
