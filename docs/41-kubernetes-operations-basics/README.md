# Kubernetes Operations Basics

This section introduces basic Kubernetes operations for learners who can already read simple manifests.

The goal is not production operations mastery. The goal is to understand what to inspect when a local learning workload does not behave as expected.

## Start Here

1. [kubectl Troubleshooting Flow](kubectl-troubleshooting-flow.md)
2. [Logs, Events, And Rollouts](logs-events-rollouts.md)
3. [Common Kubernetes Failures](common-kubernetes-failures.md)
4. [Scaling And Cleanup Basics](scaling-cleanup-basics.md)

## What You Should Learn

- How to view and describe resources
- How logs and events help explain failures
- How rollout status and rollback concepts fit together
- Why scaling is simple to request but still needs resource awareness
- How to clean up local learning resources safely
