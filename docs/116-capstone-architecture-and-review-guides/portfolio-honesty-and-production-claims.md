# Portfolio Honesty and Production Claims

The capstones are strong portfolio material when presented as designed simulations with tests and review docs. They should not be described as deployed production systems unless deployment, security, load, operations, and incident evidence exists.

## Good Language

- "This project simulates checkout failure handling with deterministic tests."
- "The design separates source-of-truth state from projections."
- "The workbench demonstrates safe local JVM diagnostic practice."

## Claims To Avoid

- The project runs real durable distributed infrastructure.
- Passing tests proves deployment readiness.
- Local simulations prove capacity or availability.
- Release preparation means a tag or GitHub release already exists.
