# Kubernetes Foundations

Kubernetes is a container orchestration platform. It lets you describe application workloads and supporting objects, then works to keep the cluster close to that desired state.

This section introduces Kubernetes vocabulary before moving into Pods, Deployments, Services, ConfigMaps, Secrets, probes, and operations.
