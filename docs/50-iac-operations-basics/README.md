# IaC Operations Basics

IaC operations are the workflows teams use to check, review, approve, apply, recover, and reconcile infrastructure changes.

This section introduces the vocabulary. It does not ask you to run real applies or destroys.

## Learning Goals

- Explain `fmt`, `validate`, and `plan`.
- Understand apply and destroy as real environment operations.
- Review plans safely.
- Describe pull request and approval workflows for IaC.
- Explain drift detection, import, failed applies, rollback, and recovery at a beginner level.

## Recommended Order

1. Read [fmt, validate, and plan](fmt-validate-plan.md).
2. Read [Review and approval workflow](review-approval-workflow.md).
3. Read [Drift, import, and failed apply](drift-import-failed-apply.md).
