# Cloud Traffic And Data Patterns

Cloud systems are easier to reason about when learners can trace traffic and data flow. This section introduces common architecture building blocks without tying them to a cloud provider.

## Learning Goals

- Trace request flow from client to backend.
- Explain load balancing, reverse proxies, and API gateways.
- Understand managed database and connection pooling concepts.
- Describe caching, queues, async jobs, object storage, and CDNs.
- Know when not to add extra components.
