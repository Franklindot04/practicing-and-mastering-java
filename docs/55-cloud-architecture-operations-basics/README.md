# Cloud Architecture Operations Basics

Operational architecture is about keeping systems understandable while they run, fail, scale, and recover.

## Learning Goals

- Monitor architecture health.
- Understand SLO, SLA, and error budget concepts.
- Reason about capacity and scaling.
- Explain retries, timeouts, backpressure, and circuit breakers.
- Prepare runbooks and incident notes.
