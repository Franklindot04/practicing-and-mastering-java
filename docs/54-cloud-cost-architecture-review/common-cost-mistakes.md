# Common Cost Mistakes

Cost mistakes are easy to make in cloud systems because many small usage-based charges can add up.

## Common Mistakes

- Leaving unused resources running.
- Scaling without max limits or alerts.
- Logging too much high-cardinality or verbose data.
- Keeping old backups or objects forever.
- Moving large data between regions without understanding transfer cost.
- Adding managed services before the need is clear.
- Treating free tier limits as production capacity.
- Ignoring queue backlog, cache size, and storage growth.

## Better Habits

- Start with simple architecture.
- Estimate what grows with users, requests, logs, and storage.
- Add budgets and alerts in real environments.
- Review cost when adding redundancy or scaling.
- Delete learning resources in real cloud accounts when they are no longer needed.
