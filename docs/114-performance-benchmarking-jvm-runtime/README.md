# Performance, Benchmarking, And JVM Runtime

This Stage 29 documentation set teaches performance engineering for Java through requirements, workload modelling, valid measurement, JMH benchmarking, JVM runtime behavior, memory, JIT compilation, garbage collection, and performance-regression prevention.

## Principle

Optimization begins with a requirement and a measurement plan. Guessing is cheaper at first and expensive later.
