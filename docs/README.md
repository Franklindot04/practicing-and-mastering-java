## How To Study A Topic

- Read the concept note.
- Type the example by hand.
- Run it.
- Change one part and predict what happens.
- Solve the matching exercises.
- Write a short explanation in your own words.

## Before Moving On

You should be able to answer:

- What problem does this topic solve?
- What syntax or API do I need to remember?
- What mistakes do beginners usually make here?
- Can I write a small example without copying?
