# Object-Oriented Programming

## Why This Matters

Object-oriented programming helps you model real concepts with data and behavior. It is central to most Java codebases.

## Topics

- Classes and objects
- Fields and methods
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Static and final
- Records and enums
- Packages and access modifiers
- Composition vs inheritance

## Before Moving On

You should be able to design a small class, protect its state, create objects, and explain when composition is clearer than inheritance.
