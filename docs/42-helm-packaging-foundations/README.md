# Helm Packaging Foundations

Helm is a package manager for Kubernetes applications. It helps group related Kubernetes manifests, expose configurable values, and track installed application releases.

This section is beginner-friendly and local-only. It does not require a real cluster, cloud account, or production deployment.

2. [Kubernetes YAML Vs Helm](kubernetes-yaml-vs-helm.md)
3. [Releases, Upgrades, And Rollbacks](releases-upgrades-rollbacks.md)

## What You Should Learn

- Why Helm exists
- How charts package Kubernetes objects
- How values make a chart configurable
- How releases connect a chart to an installed instance
