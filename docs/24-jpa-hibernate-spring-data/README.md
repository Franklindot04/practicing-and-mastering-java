# JPA, Hibernate, And Spring Data JPA

JPA, Hibernate, and Spring Data JPA help Java applications store and load relational data without writing every SQL statement by hand.

## What Each Tool Is

- JPA: a Java specification for object-relational mapping.
- Hibernate: a popular implementation of JPA.
- Spring Data JPA: Spring tooling that creates repository implementations from interfaces.
