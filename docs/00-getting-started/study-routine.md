# Study Routine

## Daily Practice Loop

1. Read one small topic.
2. Type one example by hand.
3. Run the example.
4. Break it on purpose and read the error.
5. Solve one exercise.
6. Write a two-sentence summary.

## Weekly Review

- Revisit confusing topics.
- Re-run old examples without looking.
- Build or improve one mini project.
- Add notes to your progress tracker.

## Healthy Pace

Consistent practice matters more than rushing. A good target is 45 to 90 focused minutes per study day.
