# Terraform And OpenTofu Foundations

Terraform and OpenTofu are Infrastructure as Code tools that read configuration files, compare desired state with known state, and produce plans for infrastructure changes.

This section introduces vocabulary only. It does not require real provider credentials and does not ask you to run apply or destroy commands.

## Learning Goals

- Explain Terraform and OpenTofu at a high level.
- Identify providers, resources, data sources, variables, outputs, state, plans, applies, and destroys.
- Understand why state and plan files require careful handling.
- Recognize beginner mistakes before using real infrastructure.
