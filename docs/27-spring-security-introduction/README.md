# Spring Security Introduction

Spring Security is the main security framework used in many Spring Boot applications. It helps handle authentication, authorization, password encoding, security filters, and endpoint protection.

Security examples in this repository are educational. They are not production-hardened and should be reviewed, tested, monitored, and configured carefully before real use.

2. [Password Encoding](password-encoding.md)

## Why Spring Security Exists

Security is easy to get wrong. Spring Security provides proven building blocks so applications do not invent authentication, password handling, or authorization from scratch.

## What Not To Worry About Yet

- OAuth2 and OpenID Connect
- Custom JWT infrastructure
- Refresh token rotation
- Multi-factor authentication
- Production secret management
- Cloud deployment

First, learn how protected routes, demo users, password encoding, and role checks fit together.
