# Java Interview Prep

Interview preparation should test whether you can explain concepts, write code, reason about tradeoffs, and debug mistakes.

## Topic Areas

- Java basics
- Object-oriented programming
- Collections
- Generics
- Exceptions
- Streams
- Concurrency
- JVM
- Coding challenges
- System design basics

## How To Practice

1. Explain the concept out loud.
2. Write a small example.
3. Discuss tradeoffs.
4. Solve a coding prompt.
5. Review edge cases.
