# Release And Rollback Basics

A release is a specific version of an application made available to an environment. A rollback returns to a previous known-good version or configuration.

Release and rollback planning should happen before deployment, not during panic.

## Files In This Section

- [Release Versioning](release-versioning.md)
- [Rollback Basics](rollback-basics.md)

## Learning Rule

Every deployment should answer:

- What version is being deployed?
- How will we know it works?
- What will we do if it does not work?
