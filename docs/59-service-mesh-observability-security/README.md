# Service Mesh Observability And Security

A service mesh can make service-to-service traffic easier to observe and can enforce security policy at the workload communication layer.

This section is vendor-neutral and educational. It does not include real certificates, private keys, trust bundles, kubeconfig files, or production mesh policy.

## Learning Goals

- Explain mesh observability signals.
- Compare traces, metrics, and access logs.
- Describe mTLS and workload identity at a high level.
- Recognize security limits that remain in application code and platform operations.
