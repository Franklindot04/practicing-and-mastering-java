# IaC Modules And Environments

Modules and environment folders help teams organize Infrastructure as Code as systems grow. They can reduce duplication, but they can also add confusion if introduced too early.

This section stays beginner-friendly and conceptual. It does not create real infrastructure.

## Learning Goals

- Explain why modules exist.
- Compare root modules and child modules.
- Understand module inputs and outputs.
- Plan environment folders such as dev, test, staging, and prod.
- Recognize when not to create a module.
- Avoid common module and environment mistakes.
