# Availability, Scalability, And Reliability

Availability, scalability, reliability, resilience, and fault tolerance are related cloud architecture concepts. They help learners reason about how systems behave when traffic grows or failures happen.

## Learning Goals

- Define availability, scalability, reliability, resilience, and fault tolerance.
- Compare horizontal and vertical scaling.
- Explain stateless and stateful services.
- Understand multi-instance backend services.
- Recognize graceful degradation.
