# Advanced Java Language Features

Advanced Java features are powerful when used intentionally.

Topics:

- Reflection
- Annotations
- Serialization
- Sealed classes
- Pattern matching basics

Common mistakes:

- Using reflection when normal method calls work.
- Serializing sensitive data.
- Creating annotations without runtime value.
- Making clever code hard to debug.

Practice prompts:

- Create and read a custom annotation.
- Inspect class methods with reflection.
- Serialize and deserialize a simple object for learning only.

Before moving on, you should understand the tradeoff between flexibility and complexity.
