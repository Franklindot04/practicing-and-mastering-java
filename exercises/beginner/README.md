# Beginner Exercises

Use these exercises after reading Java basics notes and running the matching examples.

## Recommended Order

- [Java Basics Exercises](java-basics.md)

## How To Practice

- [ ] Read one note from [Java Basics](../../docs/01-java-basics/README.md).
- [ ] Run or modify one file from [Beginner Examples](../../examples/beginner/README.md).
- [ ] Complete one or two exercises without looking for a full solution first.
- [ ] Write down what confused you in [Progress Tracker](../../PROGRESS.md).
- [ ] Revisit the exercise after building a beginner project.

When these exercises feel comfortable, build a project from [Beginner Projects](../../projects/beginner/README.md).
