# Cloud Readiness Exercises

## Exercise 1: Cloud Readiness Checklist

Difficulty: Beginner

Concepts practiced: application readiness, infrastructure readiness

Problem statement: Create a checklist for moving a Java API from local-only learning to a cloud-ready demo.

Hints:

- Include health checks.
- Include runtime configuration.
- Include secrets safety.

Stretch challenge: Add one cost-awareness item.

## Exercise 2: Managed Database Planning

Difficulty: Intermediate

Concepts practiced: managed databases, credentials, network access

Problem statement: Write the information an app needs to connect to a managed database without committing real credentials.

Hints:

- Host and database name are not enough.
- Think about TLS and network rules.

Stretch challenge: Explain why H2 local settings should not be reused as production guidance.

## Exercise 3: HTTPS And Domain Readiness

Difficulty: Beginner

Concepts practiced: DNS, domains, HTTPS

Problem statement: Describe what should be known before exposing a backend API publicly.

Hints:

- Include domain name.
- Include HTTPS.
- Include firewall or access rules.

Stretch challenge: Name one thing that should not be public.
