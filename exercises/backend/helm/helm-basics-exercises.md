# Helm Basics Exercises

## Exercise 1: Helm Vs Raw YAML

Difficulty: Beginner

Concepts practiced: Helm purpose, charts, raw manifests

Problem statement: Explain when raw Kubernetes YAML is easier to learn from and when a Helm chart becomes useful.

Hints:
- Think about repetition and environments.
- Think about seeing the final manifest clearly.

Stretch challenge: Name one danger of templating too early.

## Exercise 2: Chart Vocabulary

Difficulty: Beginner

Concepts practiced: chart, template, values, release

Problem statement: Define chart, template, values, and release in your own words.

Hints:
- A chart is a package.
- A release is an installed chart instance.

Stretch challenge: Explain why this repo focuses on render-only practice.
