# Event-Driven Architecture Exercises

These exercises practice event-driven architecture concepts without requiring messaging infrastructure.

## Exercise Set

- [Event-Driven Architecture Exercises](event-driven-architecture-exercises.md)

## How To Practice

- Write answers in your own words before reading solutions.
- Draw small ASCII flows for each scenario.
- Identify the event, producer, consumer, and failure behavior.
- Prefer vendor-neutral language.
