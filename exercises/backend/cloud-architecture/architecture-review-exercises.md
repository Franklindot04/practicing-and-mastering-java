# Architecture Review Exercises

## Exercise 1: Review Checklist

Difficulty: Beginner

Concepts practiced: architecture review, reliability, security, operations

Problem statement: Build a short review checklist for `Client -> DNS -> Load Balancer -> Task API Instances -> Managed Database`.

Hints: Include traffic, data, failures, cost, and secrets.

Stretch challenge: Add one question about rollback.

## Exercise 2: Complexity Review

Difficulty: Intermediate

Concepts practiced: complexity tradeoffs

Problem statement: A learner wants to add a cache, queue, CDN, and API gateway to a small task API on day one. Write a review response that keeps useful ideas but reduces unnecessary complexity.

Hints: Ask what problem each component solves.

Stretch challenge: Suggest a staged order for adding components later.
