# Cloud Architecture Basics Exercises

## Exercise 1: Architecture Boundaries

Difficulty: Beginner

Concepts practiced: application architecture, infrastructure architecture

Problem statement: Describe which parts of a task API design belong to application architecture and which belong to infrastructure architecture.

Hints: Think about code layers, runtime, database, networking, and monitoring.

Stretch challenge: Name one decision that affects both application and infrastructure.

## Exercise 2: Single Point Of Failure

Difficulty: Beginner

Concepts practiced: availability, single points of failure

Problem statement: Review `Client -> Backend Service -> Managed Database`. Name two single points of failure and one possible mitigation for each.

Hints: Look for components that have only one instance or one path.

Stretch challenge: Explain why mitigation can increase cost.
