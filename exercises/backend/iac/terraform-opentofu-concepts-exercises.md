# Terraform/OpenTofu Concepts Exercises

## Exercise 1: Classify The Block

Difficulty: Beginner

Concepts practiced: providers, resources, variables, outputs

Problem statement: For each item, say whether it is most like a provider, resource, variable, or output: cloud platform plugin, application port input, runtime service, generated service name.

Hints: Providers talk to platforms. Variables are inputs. Resources are managed things. Outputs expose selected values.

Stretch challenge: Explain why a sensitive database password should not be a normal output.

## Exercise 2: Safer Variables

Difficulty: Beginner

Concepts practiced: variable design, placeholder values

Problem statement: Design three variables for a Java backend runtime: app name, port, and health path. Include a type and a safe example value for each.

Hints: Keep the examples generic and non-secret.

Stretch challenge: Add one validation rule in plain English.
