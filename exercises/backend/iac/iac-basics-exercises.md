# IaC Basics Exercises

## Exercise 1: Manual Change Or IaC Change

Difficulty: Beginner

Concepts practiced: IaC purpose, manual infrastructure, reviewable change

Problem statement: List three risks of changing a backend runtime setting manually in a web dashboard. Then rewrite the same change as an IaC pull request description.

Hints: Think about repeatability, review history, and environment consistency.

Stretch challenge: Add one reviewer question that would catch a risky setting before merge.

## Exercise 2: Desired State

Difficulty: Beginner

Concepts practiced: declarative configuration, desired state

Problem statement: Describe desired state for a Java task API runtime with an app name, port, health check path, and environment name. Do not mention exact click-by-click steps.

Hints: Use "should be" language.

Stretch challenge: Explain how a tool might detect that the real port does not match the desired port.
